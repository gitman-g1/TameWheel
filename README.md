# TameWheel · 小滚轮

**简体中文** | [English](README.en.md)

[下载 macOS 版（公开测试）](https://github.com/gitman-g1/TameWheel/releases/tag/v0.3.0) · [安装说明](docs/install.md)

**鼠标滚轮更顺手，触控板依然自然。**

小滚轮是一款轻量的 macOS 菜单栏工具，让鼠标拥有熟悉的滚动方向和稳定的匀速手感，同时保留触控板原有的自然滚动体验。

- **熟悉的方向**：单独反转鼠标滚轮，系统保留自然滚动时，鼠标依然符合 Windows 使用习惯。
- **稳定的手感**：固定匀速步长，轻滚、快滚都保持一致，无需反复调节速度。
- **触控板保持原样**：方向、速度和惯性不变，鼠标与触控板各自顺手。
- **一个开关就够**：常驻菜单栏，开启即用；关闭即恢复系统滚动，开关状态自动记住。

适用于 macOS 13 及以上，提供 Apple Silicon / Intel 通用安装包，支持普通鼠标的垂直滚轮。首次使用需要授予辅助功能权限。

当前测试版未经过 Apple 公证，首次打开需按安装说明在系统设置中确认。
