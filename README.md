# ScrollMate

轻量的 macOS 菜单栏工具：单独调整鼠标垂直滚轮，保留触控板的方向、速度和惯性。零第三方依赖。

## 已实现

- **反转鼠标滚轮**：相对当前系统方向单独反转，适合系统保留「自然滚动」的场景。
- **匀速模式**：1–12 行固定步长，默认 3 行，消除普通滚轮事件的速度加成。
- **系统加速模式**：保留原有加速曲线，单独设置鼠标速度为 0.25–3 倍。
- **触控板保护**：连续像素、手势相位、惯性事件原样返回；缩放与软件合成输入也不改写。
- 设置自动保存、暂停/继续、恢复默认、授权检测、睡眠唤醒恢复。
- macOS 26+ 使用原生 Liquid Glass；macOS 13–15 回退为系统材质，自动跟随深浅外观。

目前处理**普通鼠标的垂直离散滚轮**。横向滚动不修改。Magic Mouse、驱动转换过的平滑滚动、高精度连续滚轮、远程输入不在当前调整范围内，优先原样通过。

## 本地构建与运行

运行要求 macOS 13+。编译需要带 macOS 26+ SDK 的 Xcode / Command Line Tools 和 Swift 6.2+，因为使用了新玻璃 API；测试所需系统版本还取决于工具链自带的 Testing 框架。本机使用 macOS 27、Swift 6.4 验证。

```sh
bash scripts/build-app.sh
open dist/ScrollMate.app
```

首次使用：

1. 在面板点击「打开辅助功能设置」。
2. 在系统设置 → 隐私与安全性 → 辅助功能中允许 ScrollMate（当前 macOS 27 可能显示为「设备控制和数据访问」）。
3. 面板显示「正在为鼠标调校」后设置立即生效，无需重启。
4. 交替滚动鼠标和触控板，面板会显示最近输入的处理情况。

应用只申请滚动处理所需的辅助功能权限，不监听键盘、不修改系统鼠标/触控板偏好。退出或暂停会移除滚动事件拦截。

本地构建使用临时签名。重新编译或移动应用后，如果开关已开启但应用仍提示未授权，请从权限列表移除旧的 ScrollMate，再添加当前路径的应用并开启；仅切换旧开关可能无效。正式分发和稳定签名留待后续处理。

## 调整手感

- 系统开启自然滚动时，打开「反转滚轮方向」通常符合 Windows 鼠标习惯。
- 推荐从「匀速 / 3 行」开始，按手感拖动速度滑块。
- 「系统加速 / 1 倍」保留系统速度曲线，方向仍可独立反转。
- 「更多操作」可恢复默认、重连服务或退出；运行状态旁可暂停。

匀速模式优先利用系统提供的合理原始整数增量保留合并的多刻度。部分驱动不提供该数据，此时每个离散滚轮事件按一个固定步长处理，面板标注「兼容匀速步长」。这种兼容方式不保证合并事件与物理刻度一一对应；不同应用对“行”的解释也可能不同。

请避免同时开启其他工具对滚动的反转/平滑处理，以免事件被重复修改。

## 验证

```sh
bash scripts/test.sh
```

14 项测试覆盖触控板/惯性事件逐字节透传、反向、倍率、低速分数累积、原始多刻度、兼容步长、暂停、横向与事件元数据保留，以及配置存取。测试不向桌面投递滚动事件。

本次用户已在 HUAWEI 鼠标和内置触控板之间交替实测，确认鼠标正常、触控板未受影响。其他设备和旧版系统尚未完成实机验证。

已实际检查浅色/深色玻璃面板、模式切换、速度滑块、倍率显示和最终应用启动；已修正首次启动时面板可能超出屏幕边界的问题。

## 目录

```text
Sources/ScrollMate/
├── App/                 # 生命周期、共享状态、服务组装
├── Features/
│   ├── MenuBar/          # 面板和授权/运行状态
│   └── Settings/         # 方向、模式、速度控件
├── Core/                # 配置、输入分类和纯滚动算法
└── Platform/            # CGEvent、原生玻璃容器、本地存储
Tests/ScrollMateTests/    # 规则与事件适配测试
Support/Info.plist
scripts/build-app.sh     # 编译并生成 .app
scripts/test.sh          # 自动兼容本机 Testing 插件
docs/architecture.md     # 层级和输入保护边界
```

优化构建使用 `bash scripts/build-app.sh release`。可用第二个参数指定输出目录，例如 `bash scripts/build-app.sh debug .build/candidate`，方便保留正在运行的构建。

开发时可以使用 `--preview-light` / `--preview-dark` 启动独立外观预览；预览不会监听系统滚动，也不保存设置。正常使用请启动 `dist/ScrollMate.app`。
