# TameWheel · 小滚轮 v0.3.1

补上应用图标：延续菜单栏的鼠标主题，独立绘制鼠标与蓝色滚轮，让安装包和 Finder 中的应用更容易识别。滚轮方向、匀速手感和触控板行为保持不变。

## 下载与安装

下载 **TameWheel-0.3.1-universal.dmg**，将 **TameWheel.app** 拖入 **Applications（应用程序）**。也提供 ZIP 版本；Assets 中的 `Source code` 是源码，不是安装包。

更新前请先右键菜单栏图标，选择“退出小滚轮”。本版仍为临时签名、未经 Apple 公证的公开测试版；首次打开和升级后的权限确认请参考[安装说明](https://github.com/gitman-g1/TameWheel/blob/v0.3.1/docs/install.md)。

要求 macOS 13 及以上，包含 Apple Silicon / Intel 两种架构。现有实机验证环境为 Apple Silicon / macOS 27，Intel 和更早系统仍待实测。校验文件：`SHA256SUMS.txt`。

---

Adds an original mouse-and-blue-wheel app icon so TameWheel is recognizable in the installer and Finder. Mouse-wheel behavior and trackpad handling are unchanged.

Download **TameWheel-0.3.1-universal.dmg** and drag the app into **Applications**. A ZIP is also available. Quit the previous version before replacing it.

This public preview is ad-hoc signed and has not been notarized by Apple. See the [installation guide](https://github.com/gitman-g1/TameWheel/blob/v0.3.1/docs/install.en.md) for first launch and Accessibility permission after updates.

Requires macOS 13 or later. Includes Apple Silicon and Intel binaries; hardware testing so far covers Apple Silicon / macOS 27. Checksums: `SHA256SUMS.txt`.
